# 学术附件元数据检索（演示）

一个纯静态页面，用于检索公开论文附件（数据集 / 补充材料 / 代码包）的**描述性元数据**。

## 运行

无需构建，任意静态服务器即可：

```bash
cd academic-attachments
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

也可直接用浏览器打开 `index.html`（使用 `file://` 时详情页哈希路由同样可用）。

## 功能

- **检索列表**：标题、类型（数据集/补充材料/代码包）、大小、来源说明、更新时间；支持多关键词搜索（标题/摘要/作者/出处/来源）、类型筛选、按更新时间/相关度/标题排序。
- **详情页**：仅展示**摘要**与**文件结构**（发布方公布的清单树），不提供访问指引或任何外链。
- **哈希路由**：`#/` 列表，`#/item/ATT-2024-0001` 详情，可收藏/分享。

## 合规设计（重要）

本系统**只索引元数据**，刻意不提供以下任何内容：

- 文件实体、文件直链、镜像或种子；
- 账号共享、越权链接、凭证复用等**绕过授权**的手段；
- 对受控数据（伦理审批 / DUA / DAC 授权）的规避指引。

受控资源以"受控访问"徽标显式标注；详情页严格限定为摘要与文件结构清单，不含任何外链或访问指引。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架 |
| `styles.css` | 学术风格样式 |
| `data.js` | 附件元数据（9 条虚构样例） |
| `app.js` | 搜索、筛选、排序、哈希路由、文件树渲染 |

数据为虚构演示数据；接入真实系统时，将 `data.js` 的 `ATTACHMENTS` 替换为经发布方授权同步的元数据即可，元数据中只保留描述性信息与文件清单，不保存任何文件内容或访问链接。
